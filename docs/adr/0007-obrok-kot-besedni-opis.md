# Obrok kot besedni opis z oceno kalorij

## Kontekst in problem

Športnik čez dan beleži obroke in vnos kalorij, prehranski svetovalec pa to spremlja. Vnos mora biti hiter. Določiti je bilo treba, kako športnik vnese obrok.

## Obravnavane možnosti

* Obrok kot besedni opis z ročno oceno kalorij
* Baza živil s kalorijami in makrohranili

## Odločitev

Izbrana možnost: »Obrok kot besedni opis z ročno oceno kalorij«, ker je vnos hiter: kratek opis in ena številka.

### Posledice

* Dobro, ker za MVP ni treba pripravljati baze živil.
* Slabo, ker so kalorije samo športnikova ocena in zato manj natančne.
* Slabo, ker aplikacija ne beleži makrohranil. Baza živil s kalorijami in makrohranili je med kasnejšimi nadgradnjami.
